# FileMorph

**FileMorph** is a lightweight, modern desktop file utility built with **Tauri v2** and **Rust**.

## 🚀 Download & Install
Ready to use FileMorph? You can grab the latest Windows setup installers (`.msi` and `.exe`) directly from the **[Releases](../../releases)** page of this repository. Just download, install, and run!

## ✨ Features
* Fast and secure desktop performance.
* Clean, intuitive user interface.
* Native Windows support.
